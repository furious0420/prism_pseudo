# =============================================================================
# SECTION 1 — INSTALL ORDER (read this, it is the only ordering trap)
# =============================================================================
#
# If you have an NVIDIA GPU, install torch FIRST, from NVIDIA's index, BEFORE
# running this file. Both ultralytics (Day 6) and sentence-transformers (Day 3)
# depend on torch, and if either installs it first you get the DEFAULT PyPI
# wheel, which on Windows is CPU-ONLY. Nothing errors. Everything just runs many
# times slower, and you will waste Day 6 concluding the laptop cannot cope when
# the real problem is that torch never saw the GPU.
#
#   Step 1 (GPU machines only — match cu121 to your nvidia-smi CUDA version):
#     pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
#
#   Step 2 (everyone):
#     pip install -r requirements.txt
#
#   Step 3 (verify — do not skip, this is the whole point of step 1):
#     python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
#     Must print True on a GPU machine. If it prints False, uninstall torch and
#     redo step 1.
#
# torch is deliberately NOT pinned in this file so step 1 wins. It arrives as a
# dependency of ultralytics/sentence-transformers if you skip step 1.
